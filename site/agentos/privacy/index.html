AgentOS Privacy Policy

Elder World Studio · Effective October 11, 2026 · DRAFT pending review

AgentOS is an app by Elder World Studio ("we") that runs a team of AI agents on the GitHub repositories you connect. This policy explains what we collect and why.

What we collect

  • Account: your email address, and if you use GitHub sign-in, your GitHub user ID, username and public profile name.
  • Repository access: the repositories you choose when you install the AgentOS GitHub App. We request read/write access to code and pull requests on those repositories only. We do not store your source code beyond the life of a task, except the diff and test output shown on your approval cards.
  • Chat and task data: your messages to the Coordinator, the tasks it creates, summaries, diffs, test results and review notes.
  • Usage and billing: AI usage per task, plan, and payment status. Card details are handled by our payment processor; we never see your full card number.
  • Technical: IP address and request logs, used for security and rate limiting.

How we use it

To run the service, enforce usage caps, bill you, keep the service secure, and support you. We never use your code, chats or repository data to train AI models, and our AI providers are contractually barred from training on data we send through their APIs.

Security

Each workspace is isolated. Secrets are encrypted at rest (AES-256-GCM). GitHub access uses short-lived tokens scoped to one repository per task. Agents work on branches and open pull requests; nothing is merged without your approval.

Retention and deletion

Task sandboxes are deleted when a task ends. Account data is kept while your account is active and deleted within 30 days of an account deletion request. Uninstalling the GitHub App revokes repository access immediately.

Your rights

You can access, export or delete your data by emailing annaews@agentmail.to. AgentOS is not directed at children under 13.

Changes

We'll post updates here and notify you in the app for material changes.
